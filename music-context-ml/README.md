# Context-aware Music Preference Prediction

## Problem

Traditional music recommendation systems focus on songs.

However, users often listen differently depending on:

- activity
- emotion
- time
- context

This project explores whether contextual information improves prediction performance.

---

## Research Question

Can music features and contextual information predict user preferences better than music features alone?

---

## Hypothesis

H1:
Context information improves prediction.

H2:
Emotion and activity tags have strong influence.

H3:
Behavior information further improves performance.

---

## Candidate Features

Music:

- danceability
- energy
- tempo
- valence
- acousticness

Context:

- study
- workout
- cafe
- night
- happy
- sad

Behavior:

- skip
- replay
- like
